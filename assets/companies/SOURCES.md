These marks appear under “Erfarenhet från” in Peter’s personal introduction. They identify the professional background supplied by Peter; they are not labelled as course partners or sponsors.

- Klarna: official wordmark SVG from the navigation on https://brand.klarna.com/trademarks (downloaded 2026-10-30). Path geometry preserved; explicit fill replaces currentColor for use as an image.
- Nordnet: official corporate website logo, https://nordnetab.com/wp-content/uploads/2020/10/Nordnet_logo-220x24.png (downloaded 2026-10-30). Original asset preserved; displayed in monochrome via CSS brightness for contrast on the light site background.

- Forefront: official black wordmark from https://www.forefront.se/ — asset https://cdn.prod.website-files.com/6520266392f9ba32695e8f6e/660eb67eae7da75f483bb24b_ff-logo-black.svg (downloaded 2026-10-30). Original SVG preserved.
- Irori: official site header image from https://irori.se/ — asset https://irori.se/wp-content/uploads/sites/5/2023/08/irori-logo-web-2-light-1.png (downloaded 2026-10-30). Original PNG preserved, displayed in monochrome via CSS for the light site background.
- Kustom: official navigation wordmark SVG from https://www.kustom.co/sv (downloaded 2026-10-30). Geometry preserved; currentColor replaced with explicit dark fill for standalone image use.
